# Accessible org charts

Three D3.js prototypes that show an organization as a radial chart that doesn't depend on a mouse. They are static HTML pages built with accessibility as a requirement.

## Why

Org charts are usually pictures. A screenshot of boxes and lines tells a screen reader user nothing, and large charts are hard to use with a keyboard or at high zoom. These prototypes show the same information in forms that work with a keyboard, a screen reader and a text search.

## The charts

- **`radial_dendogram.html`**: a collapsible radial tree. Each node announces its name, title, department and whether it is expanded.
- **`radial_org_chart.html`**: a radial sunburst you can drill into.
- **`radial_sunburst.html`**: an extended sunburst that loads `org_data.csv` and falls back to embedded data when the file can't be fetched.

From the code, what they share:

- arcs are keyboard-focusable and carry `aria-label`s with name and title;
- a "Select a name" control jumps to a person, and a nested list of the same hierarchy is built next to the chart, so the structure is also available as text;
- colours are set through CSS variables.

`index.html` links to all three.

## Data

All data is **synthetic**. `radial_dendogram.html` builds a random fictional org in the page each time it loads. The other two use a fictional "Example Publishing Co." org generated by `make_synthetic_data.py` with a fixed seed from common first and last names, so any resemblance to a real person is coincidence.

```bash
python3 make_synthetic_data.py   # rewrites org_data.csv (node_id, manager_id, name, department, title)
```

`org_data.csv` is read by `radial_sunburst.html` when served over HTTP. Opened from disk, the pages use the smaller dataset embedded in each file.

## Run it

```bash
python3 -m http.server 8000
# open http://localhost:8000/
```

D3 v7 loads from the d3js.org CDN.

## Status

These are prototypes and have not been through a formal accessibility audit. They have not been verified against WCAG, and no conformance is claimed. Keyboard, screen reader, 400% zoom and forced-colours testing is still to do. Issues and test reports are welcome.
